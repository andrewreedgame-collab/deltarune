Chapter 5 Emulator Feature Guide

Use this page as the Chapter 5 launch hub. It lists the common emulator features that make playing a port more comfortable and powerful.

  • Save State / Load State — instant save and resume from any moment.
  • Fast Forward — speed up cutscenes and long gameplay sections.
  • Slow Motion — slow the game for precise timing or easier navigation.
  • Pause / Resume — suspend gameplay while keeping the session alive.
  • Rewind — step backward to recover from mistakes.
  • Frame Advance — move one frame at a time for precise control.
  • Fullscreen — expand the canvas to fill the screen.
  • Audio Controls — mute, unmute, or adjust sound while playing.
  • Restart / Reset — restart the current chapter or scene quickly.
  • Screenshot / Capture — save important moments or progress screens.
